# TimeCool

ระบบลงเวลาทำงานของบริษัท คูลอินโนเทค จำกัด

- ลงเวลาเข้า-ออกงานพร้อมรูปยืนยันและตำแหน่ง GPS
- ขอลา / ขอ OT และผู้จัดการอนุมัติ ตามระเบียบบริษัท
- รายงานประจำเดือน สาย ขาดงาน ใบเตือน และส่งออก Excel
- วันหยุดประจำปีและวันทำงานจันทร์–ศุกร์

> ตอนนี้ทำงานในโหมดสาธิต: ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น
> ต้องเชื่อมฐานข้อมูลออนไลน์ (เช่น Firebase) ก่อนใช้งานจริงกับพนักงานหลายคน
